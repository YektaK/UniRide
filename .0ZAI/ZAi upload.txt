 Dropbox ile Dosya Yükleme
Adım 1: Dropbox App Oluşturun
https://www.dropbox.com/developers/apps adresine gidin
"Create app" butonuna tıklayın
Şu seçenekleri yapın:
Seçenek
Değer
API	Scoped access
Access	App folder (Sadece bir klasöre erişim - daha güvenli)
App name	UniRideUpload (veya istediğiniz isim)

"Create app" butonuna tıklayın
Adım 2: İzinleri Ayarlayın
App sayfasında:

Permissions sekmesine tıklayın
Files and folders bölümünden:
✅ files.content.write (yazma izni)
✅ files.content.read (okuma izni)
"Submit" butonuna tıklayın
Adım 3: Access Token Oluşturun
Settings sekmesine tıklayın
OAuth 2 bölümüne gidin
"Generate access token" butonuna tıklayın

Adım 4: Bana Token'ı Verin
Token'ı buraya yapıştırın, ben dosyayı yükleyeyim:

text

Token: sl.Bxxxxxxxxxxxx...
Adım 5: Ben Yüklerim
Token geldikten sonra şunu çalıştıracağım:

bash

curl -X POST https://content.dropboxapi.com/2/files/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Dropbox-API-Arg: {\"path\": \"/UniRide_Dokumantasyon_v2.0.zip\",\"mode\": \"add\",\"autorename\": true,\"mute\": false}" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @/home/z/my-project/download/UniRide_Dokumantasyon_v2.0.zip
🔐 Güvenlik Notu
Token sadece bir klasöre erişir (App folder seçtiyseniz)
İşiniz bitince Dropbox developer sayfasından token'ı revoke edebilirsiniz
Token'ı kimseyle paylaşmayın (ben sadece bu oturumda kullanacağım)
📁 Dosya Nereye Gider?
App folder seçtiyseniz: Dropbox/Apps/UniRideUpload/ klasörüne
İsterseniz Dropbox'ta klasör adını değiştirebilirsiniz
Token'ı oluşturup buraya yapıştırın, hemen yükleyelim.
