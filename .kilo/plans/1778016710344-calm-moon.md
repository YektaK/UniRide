## 🔴 CRITICAL Issues (2)

### C1. `pso_solver.py` — Missing `Optional` import causes NameError on import

**File:** `academic_benchmark/bildiri2026/core/pso_solver.py:51`  
**Description:** The `PSOOptimizer.__init__` signature uses `Optional[int]` for `random_seed`, but `Optional` is not imported. Line 24 imports only `from typing import List, Tuple`.  
**Impact:** `from core import PSOOptimizer` raises `NameError: name 'Optional' is not defined`. This breaks `bildiri2026/core/__init__.py:18` and any script that imports the core package.  
**Fix:** Add `Optional` to the import: `from typing import List, Tuple, Optional`

---

### C2. `run_targeted.py` — Wrong `SCRIPT_DIR` calculation breaks all file paths

**File:** `academic_benchmark/bildiri2026/run_targeted.py:9`  
**Description:** `SCRIPT_DIR = os.path.dirname(os.path.abspath('3_run_benchmark.py'))` resolves to CWD + `3_run_benchmark.py`, NOT the script's own directory. If the script is run from any directory other than `bildiri2026/`, all file paths break.  
**Impact:** `data/tuned_parameters_db.json` (line 32), `data/tsplib/` (line 47), and `results/` (line 37) all resolve to wrong paths. Script crashes with `FileNotFoundError`.  
**Fix:** Change to `SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))`

## 🟠 MAJOR Issues (4)

### M1. `numba_accel.py` — Unconditional `import numpy` without try/except

**File:** `academic_benchmark/bildiri2026/core/numba_accel.py:8`  
**Description:** `import numpy as np` is NOT guarded. If numpy is not installed, importing `numba_accel` raises `ModuleNotFoundError`. This cascades to ALL solver modules (`ga_solver.py:22`, `pso_solver.py:26`, `two_opt.py:15`, `three_opt.py:6`, `or_opt.py:6`) since they all do `from . import numba_accel as _nb` at module level.  
**Impact:** The entire `bildiri2026.core` package becomes unusable without numpy.  
**Fix:** Wrap in try/except:
```python
try:
    import numpy as np
    _NUMPY_AVAILABLE = True
except ImportError:
    _NUMPY_AVAILABLE = False
    np = None
```
Then guard JIT functions with `_NUMPY_AVAILABLE` checks.

---

### M2. `5_visualize.py` — Hard imports of pandas/matplotlib/seaborn crash on import

**File:** `academic_benchmark/bildiri2026/5_visualize.py:12-14`  
**Description:** `import pandas as pd`, `import matplotlib.pyplot as plt`, `import seaborn as sns` are unconditional top-level imports. If any are missing, the script crashes before `main()` is reached.  
**Impact:** Script cannot even be imported for help/usage without all visualization libraries installed.  
**Fix:** Move imports inside functions or wrap in try/except with clear error message.

---

### M3. `master_sota_engine.py` — Type annotation references undefined `TSPLIBProblem`

**File:** `academic_benchmark/master_sota_engine.py:652,746`  
**Description:** Function signatures use `List[TSPLIBProblem]` but the dataclass defined at line 191 is `TSPProblem`, not `TSPLIBProblem`. `TSPLIBProblem` is from `dataset_loader.py` and is NOT imported in this module.  
**Impact:** No runtime error (Python ignores type hints at runtime), but mypy/type-checkers will flag this. More importantly, it's misleading documentation — the functions accept `TSPProblem` objects, not `TSPLIBProblem`.  
**Fix:** Change `TSPLIBProblem` → `TSPProblem` in the type annotations at lines 652 and 746.

---

### M4. `run_targeted.py:32` — Relative file path breaks outside CWD

**File:** `academic_benchmark/bildiri2026/run_targeted.py:32`  
**Description:** `open('data/tuned_parameters_db.json', 'r')` uses a relative path. Combined with the wrong `SCRIPT_DIR` (C1), this fails unless CWD is exactly `bildiri2026/`.  
**Impact:** `FileNotFoundError` when running from project root or any other directory.  
**Fix:** Use `os.path.join(SCRIPT_DIR, 'data/tuned_parameters_db.json')` (after fixing C2).
