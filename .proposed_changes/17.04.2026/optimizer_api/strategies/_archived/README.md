# Archived Strategies

This directory contains routing strategies that have been retired and are **not** registered in the active `STRATEGY_REGISTRY`.

| File | Reason |
|---|---|
| `kmeans_tsp.py` | Proof-of-concept skeleton only — never implemented beyond dummy sequential routing. K-Means clustering within the routing pipeline has been superseded by the Optimal Split Decoder (Pipeline B: `ga_split`, `pso_split`, etc.) and the FCM/Hierarchical clustering utils. Will not be used in future versions. |

Files in this directory are kept for reference only and are **not imported** anywhere.
