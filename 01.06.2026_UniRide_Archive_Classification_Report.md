> **Date:** 2026-06-01

---

## 1. Executive Summary

The project contains **3 categories of clutter** that should be moved out of the active code path, plus **3 categories of value** that must be preserved:

| Category | Action | Approx. Volume |
|---|---|---|
| **Editor / agent tool state** | Gitignore (do not archive) | 50 MB+ |
| **Superseded code (split vs non-split, duplicated utils, re-export shims)** | Move to `archive/legacy_code/` | ~25 files / ~3 000 LoC |
| **Old AI-proposed change packages** | Move to `archive/proposed_changes_history/` | 4 dated snapshots |
| **Active algorithm + API code** | **KEEP** as mandatory | ~6 000 LoC |
| **Documentation, roadmaps, reviews, plans** | **KEEP** as knowledgebase | ~50 .md files |
| **Test infrastructure** | **KEEP** (with subset to archive) | ~80 test files |

**Net effect if executed:** the working tree shrinks by roughly 40% while every active code path continues to function and every historical decision remains auditable.

---

## 2. Classification Legend

- 🟢 **MANDATORY** — actively imported / executed. **Do not move, do not delete.**
- 🟡 **KNOWLEDGEBASE** — historical / decision-tracking value. **Keep, but no longer in the hot path.**
- 🟠 **ARCHIVE CANDIDATE** — superseded, duplicated, or superseded tooling. **Move to `archive/` once confirmed unused.**
- ⚪ **TOOL STATE** — editor/agent cache, regenerable. **Should be in `.gitignore`, not archived.**
- 🔴 **SUPERSEDED-BY-EVIDENCE** — has a known newer replacement, see "Replacement" column.

## 14. Final Verdict

The project's **algorithms and benchmark infrastructure are solid and should not be archived.** The **API strategy layer has clear, well-bounded duplication** (the 4 non-split strategies, the 8 sota_common re-exports, the duplicated utils, the duplicated clustering strategies) that is **safe to archive** after the §10 grep verification.

The **documentary layer is the project's greatest asset** — the `docs/` directory contains decision rationale, design scoring matrices, multi-version review history, and an institutional audit trail that is **rare in research codebases and must not be lost.** Archive only with care, and only files that are demonstrably not in the active import graph.

The **tool / editor / agent state folders** (`.codegraph/`, `.opencode/`, `.cursor/`, `.proposed_changes/`, `scratch/`, etc.) are clutter that should be gitignored rather than archived — they have no value beyond a single working session.
