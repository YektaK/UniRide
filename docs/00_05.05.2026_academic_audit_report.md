## Metodoloji Kısmı İçin Önemli Notlar

> Bu bölüm akademik makalede "Metodoloji" veya "Implementation Details" altında belirtilmesi gereken kısıtları ve üstünlükleri özetler.

### Belirtilmesi ZORUNLU Kısıtlar

1. **R²DMA Rezonans Örneklemesi:** Mevcut implementasyon tam popülasyon rezonansı hesaplar. Büyük problemlerde (n>200) zaman bütçesi nedeniyle örnekleme yapılabilir.
2. **Çeşitlilik Ölçümü Örnekleme:** E²BSO ve R²DMA'da çeşitlilik metrikleri tam popülasyon yerine 5 birey üzerinden hesaplanmaktadır.
3. **Numba Bağımlılığı:** Numba mevcut değilse algoritmalar pure Python ile çalışır; bu durumda benchmark süreleri Numba'lı çalışmadan 5-10x daha uzun olabilir.
4. **TSPLIB EUC_2D Mesafesi:** `int(sqrt(...) + 0.5)` yuvarlama kullanılıyor — bu TSPLIB standardıdır, ancak diğer mesafe tipleri (GEO, ATT) desteklenmiyor.

### Belirtilebilecek Üstünlükler

1. **Hibrid ALNS:** Tüm 3 algoritma Shaw/Worst/Random/Related destroy + Greedy/Regret2/Regret3 repair kombinasyonuyla tam ALNS desteği sunuyor.
2. **Çok Katmanlı Yerel Arama:** 2-opt → Or-opt → 3-opt → Swap zinciri, intensite parametresiyle kontrol edilebilir.
3. **Deterministic Seeding:** `random.Random(seed)` ile tam yeniden üretilebilirlik (pure Python path'de).
4. **Adaptive Thresholds:** E²BSO'nun EMA tabanlı eşik öğrenmesi ve R²DMA'nın theta adaptasyonu dinamik parametre ayarının iyi örnekleridir.
