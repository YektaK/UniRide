## 🔴 B1 — R²DMA Rezonans O(n_pop²×n) Darboğazı

**Mevcut Durum:** `r2dma_tsp.py:223-232` — Her birey için TÜM popülasyonu tarıyor.

### Seçenek A: Tournament-Based Partner Selection (ÖNERİLEN)
```python
# Her birey için k=5 rastgele aday seçilir, en yüksek rezonansla eşleştirilir
candidates = rng.sample(range(len(population)), min(k, len(population)))
best_partner = max(candidates, key=lambda j: _compute_resonance(...))
```

| Kriter | Değer |
|--------|-------|
| **Avantaj** | O(n_pop×k×n) — k=5 için ~12x hızlanma. Akademik standart (GA/PSO literature) |
| **Dezavantaj** | En iyi partner'ı kaçırma olasılığı (%8-15 kalite kaybı, ancak stokastik doğa zaten bu riski içerir) |
| **Hesaplama Maliyeti** | n_pop=60, k=5 → 300 resonance/iter (mevcut: 3600) |
| **Yayınlanabilirlik** | ✅ Yüksek — Tournament selection standart akademik yöntem |

### Seçenek B: Precomputed Resonance Cache
```python
# Her segment_size iterasyonda rezonans matrisini tamamen hesapla ve cache'le
if t % cache_refresh_interval == 0:
    resonance_matrix = [[_compute_resonance(pop[i], pop[j], n, dm) for j in range(pop_size)] for i in range(pop_size)]
```

| Kriter | Değer |
|--------|-------|
| **Avantaj** | Her zaman optimal partner. Cache ile amortisman |
| **Dezavantaj** | Bellek: O(n_pop²) matrix. Stale cache riski |
| **Hesaplama Maliyeti** | Her refresh: O(n_pop²×n), ama 50 iterasyonda 1 kez = etkili olarak O(n_pop²×n/50) |
| **Yayınlanabilirlik** | ⚠️ Orta — Cache tabanlı yaklaşım makalede ekstra açıklama gerektirir |

### Seçenek C: Nearest-Neighbor Resonance (Sadece komşularla)
```python
# Pop sıralamasına göre sadece ±window komşuları kontrol et
window = 5
candidates = population[max(0,i-window):i] + population[i+1:min(len(pop),i+window+1)]
```

| Kriter | Değer |
|--------|-------|
| **Avantaj** | O(n_pop×window×n), deterministik |
| **Dezavantaj** | Popülasyon sırası anlamsız olduğu için biyolojik motivasyonu zayıf. Kalite kaybı yüksek |
| **Hesaplama Maliyeti** | window=5 için ~300 resonance/iter |
| **Yayınlanabilirlik** | ⚠️ Düşük — Gerekçelendirilmesi zor |
