# **App Name**: UniRide Assist

## Core Features:

- Vehicle Management: Admin module for managing vehicles (number, type, wheelchair capacity, seating capacity).
- User Profiles: User registration and profile management with address and accessibility needs.
- Schedule Submission: Weekly schedule input by users, showing desired arrival and departure times; admin pre-fill option.
- Smart Notifications: AI-powered schedule updates: an AI tool proactively determines optimal pickup and drop-off times based on student schedules and admin-defined parameters. It reasons whether the timing makes sense based on other schedule commitments, sending notifications with 'Approve,' 'Change,' and 'Cancel' options.
- Ad-hoc Ride Requests: Request ad-hoc rides outside scheduled times, with specified pickup and drop-off.
- Location Services: Integration of Google Maps to display user location and enable location selection on a map.
- Service Tracking: Real-time display of vehicle location on a map, offering service tracking for users.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability.
- Background color: Light gray (#F0F2F5) for a clean, accessible interface.
- Accent color: Teal (#4CAF50) for key interactive elements and calls to action, promoting ease of use.
- Use clear, accessible fonts for easy readability.
- Simple, intuitive icons for navigation and actions.
- Responsive layout design for compatibility with various screen sizes and devices.
